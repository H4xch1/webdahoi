# Visual system

Palette follows the installed Guru skin: ink/navy background, warm ivory text, muted stone text, restrained gold borders and buttons.
Headings use the existing Playfair font variable/serif fallback. Body controls remain readable sans-serif.
The original moonlit academy and ornamental-frame assets are reused from your installed theme.
Danger/success states remain distinct rather than turning every control gold.
Global role skin and local dashboard CSS are separate from TSX.
Desktop: six flexible summary tiles, three action cards, two supporting panels when space allows.
Tablet: cards become two columns, supporting panels stack.
Phone: cards stack; stats use two columns (one on very narrow screens); controls wrap with 44px minimum button height.
Focus rings, real error states, empty states, loading feedback, background reduced-motion rules, and existing authorization are retained.
